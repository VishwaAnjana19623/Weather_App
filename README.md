# WeatherApp using Android Studio

A native Android application designed to provide real-time weather updates and forecasts. 

##  About the Project

WeatherApp is a multi-screen Android application built to deliver a seamless and intuitive weather checking experience. It features a custom user interface across multiple activities and utilizes standard Android architecture. 

### Key Features 
* **Real-time Weather Data:** Get current temperature, humidity, and conditions for your location.
* **Forecasts:** View upcoming weather trends and daily forecasts.
* **Multi-Screen UI:** Clean navigation between the home dashboard and detailed weather views.
* **Custom Iconography:** Features a custom sun-and-cloud launcher icon.

##  Built With

* [Android Studio](https://developer.android.com/studio) - The official IDE for Android development.
* **Language:** Java / Kotlin (Specify which one you used)
* **Build System:** Gradle
* **Minimum SDK:** API 21 (Android 5.0) 

##  Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

* Android Studio (latest version recommended)
* An Android device or Emulator running API 21 or higher.
* *[Optional]* API Key from your weather data provider (e.g., OpenWeatherMap, WeatherAPI).
